# Interview Questions

This repo collects Go (Golang) interview questions with answers for preparing for Backend, Medior, and Senior Go engineer interviews.

It is a personal reference and study companion to use alongside hands-on practice. LeetCode-style tasks live in a separate private repository. The playbook is written in Serbian.

## Contents

- [Go Interview Playbook](go-interview-playbook.md) — 40 common Go interview questions with answers, covering basics, slices and maps, concurrency, runtime internals, production patterns, plus 12 coding tasks, 5 traps and 10 senior scenarios; written in Serbian.

## How to use

Read a section and answer the question before looking at the written answer. Do the coding tasks on your own, then compare your solution. Use the traps and senior scenarios to practice explaining the tradeoff, not only the syntax.
